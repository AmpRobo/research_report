### 1. 雅可比矩阵

```
关节速度 q̇ → 末端线速度与角速度
末端力/力矩 → 各关节需要的静力矩
```

这两类问题由同一个矩阵联系：**雅可比矩阵 \(J\)**。

---

### 2. 刚体的速度由两部分组成

刚体运动可分成：

- **线速度**：某个点移动得多快；
- **角速度**：刚体绕某个瞬时转轴旋转得多快。

机械臂末端的速度通常组合成六维向量：

```
前三项：末端线速度
后三项：末端角速度
```

因此，即使末端位置不变，只要工具在原地转动，末端仍然有非零速度。

### 3. 同一刚体不同点的速度不同

若刚体正在转动，末端、腕部、夹爪尖端的线速度通常不同。

一个点 Q 的速度等于参考点 P 的线速度，加上刚体旋转带来的切向速度。  
这就是为什么机械臂越靠近工具尖端，因旋转产生的线速度往往越大。

### 4. 雅可比矩阵：关节速度到末端速度的映射

雅可比矩阵描述：

> 每个关节的微小速度，对末端线速度和角速度分别贡献多少。

基本关系是：

```
末端速度 = 雅可比矩阵 × 关节速度
```

对于 \(n\) 自由度机械臂：

- \(J\) 的行数通常是 6；
- 列数是关节数 \(n\)；
- 每一列对应一个关节对末端运动的贡献。

转动关节会同时影响末端的线速度和角速度；移动关节通常只直接贡献某一方向的线速度。

### 5. 雅可比矩阵的两种主要求法

**直接微分法**

对正运动学中末端位置、姿态关于关节变量的表达式求偏导。  
适合自由度较少、公式相对简单的机械臂。

**速度传播法**

从基座开始，逐节递推每根连杆的角速度和线速度，最后得到末端速度。  
适合程序实现和多连杆机械臂。

### 6. 奇异位形

当雅可比矩阵降秩时，机械臂处于奇异位形。

常见后果：

- 末端丢失某个方向的速度能力；
- 末端想实现很小的运动，关节却需要极高速度；
- 某些末端力可以用很小的关节力矩抵抗；
- 逆运动学解不稳定，关节角可能突变。

对于六自由度、方阵雅可比，常用 \(\det(J)=0\) 判断奇异性；更一般地应判断矩阵秩。

### 7. 静力问题：末端受力如何传递到关节

当机械臂静止托住工件、推墙、装配或打磨时，末端会受到：

- 三维力；
- 三维力矩。

两者合起来称为**力旋量/广义力**，也常称为 wrench。

静力分析要解决的是：

> 已知末端受到的力和力矩，各关节至少要提供多大力矩才能保持静止平衡？

核心关系是：

```
关节力矩 = 雅可比矩阵转置 × 末端力旋量
```

这也是本章最重要的结论之一。

### 8. 速度与静力的对偶关系

速度映射：

```
V = Jq̇
```

静力映射：

```
τ = JᵀF
```

两者之所以形成转置关系，是因为功率必须一致：

```
关节功率 = 末端功率
```

这也说明：雅可比矩阵不仅描述“如何动”，还描述“如何传力”。

### 9. 坐标系变化会影响速度和力的分量

速度、力和力矩都依赖描述它们的坐标系。

同一个力在工具坐标系、腕部坐标系或世界坐标系下，分量会不同。  
在切换坐标系时，必须同时处理：

- 旋转造成的方向变化；
- 参考点变化造成的力矩变化。
