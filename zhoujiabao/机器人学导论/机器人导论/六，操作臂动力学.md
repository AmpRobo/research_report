### 1. 动力学研究的问题

动力学研究力、力矩与运动之间的关系。

有两类常见问题：

- **逆动力学**：给定关节位置、速度、加速度，求执行器应输出的关节力矩；
- **正动力学**：给定关节力矩，求机器人会产生怎样的加速度和后续运动。

```
逆动力学：
q、q̇、q̈ → τ

正动力学：
τ → q̈ → q̇、q
```

### 2. 动力学模型需要哪些物理参数

仅知道连杆长度还不够。每根连杆还需要：

- 质量；
- 质心位置；
- 绕质心的惯量张量；
- 重力方向与大小；
- 末端外力或外力矩；
- 必要时还包括摩擦、减速器与电机特性。

所以，运动学模型决定“能否到达”，动力学模型决定“需要多大驱动力”。

### 3. 刚体加速度

刚体的加速度由三类因素组成：

- 参考点自身的线加速度；
- 角加速度产生的切向加速度；
- 角速度产生的向心加速度。

机械臂连杆转得越快、离关节轴越远，向心加速度越明显；这也是高速运动时力矩需求显著增大的原因。

### 4. 牛顿—欧拉方程

对每根刚体连杆，使用两条基本方程：

- 牛顿方程：力决定质心的线加速度；
- 欧拉方程：力矩决定刚体的角加速度。

牛顿—欧拉方法把多连杆机械臂视为刚体链：

```
正向递推：基座 → 末端
计算角速度、角加速度、质心加速度

反向递推：末端 → 基座
计算力、力矩、关节驱动力矩
```

它适合实际程序计算，计算量通常随关节数线性增长。

### 5. 拉格朗日方法

拉格朗日方法从系统总能量出发：

- 动能：来自连杆平动和转动；
- 势能：主要来自重力；
- 拉格朗日函数：动能减去势能。

再对每个广义坐标 \(q_i\) 写拉格朗日方程，即可得到关节力矩方程。

它特别适合：

- 手工推导较小机械臂的符号方程；
- 分析惯量、耦合与重力项；
- 建立控制器所需的标准动力学形式。

### 6. 标准操作臂动力学方程

机器人动力学通常写成：

```
关节力矩
=
惯性项
+
速度耦合项
+
重力项
+
外力项
+
摩擦等非理想项
```

含义如下：

- **惯性项**：让连杆产生关节加速度所需的力矩；
- **科氏力与离心力项**：多关节同时运动、连杆转动时产生的耦合力矩；
- **重力项**：抵抗连杆与负载重力所需的力矩；
- **外力项**：末端接触环境、搬运负载时传回关节的力矩；
- **摩擦项**：传动、轴承、齿轮等带来的额外阻力。

### 7. 关节耦合

一个关节加速，通常不只影响自身。

例如机械臂伸直后抬起前臂，肩关节、肘关节都可能需要补偿；若多个关节同时高速运动，还会出现明显耦合。

因此，单关节 PID 在轻载低速时可能够用，但高速、高精度或重载任务通常需要动力学前馈补偿。

### 8. 外力与雅可比矩阵

末端受到外力或力矩时，会通过雅可比矩阵转化为关节力矩。

例如：

- 夹爪抓住工件；
- 机械臂推门；
- 打磨或插装；
- 蛇形机器人某一节接触地面或障碍物。

这连接了第五章的静力分析与第六章的完整运动方程。

### 9. 动力学模型的实际用途

- 计算电机和减速器的力矩需求；
- 重力补偿；
- 前馈控制与计算力矩控制；
- 搬运不同载荷时调节控制参数；
- 仿真与能耗估计；
- 碰撞、接触和柔顺控制的基础。
