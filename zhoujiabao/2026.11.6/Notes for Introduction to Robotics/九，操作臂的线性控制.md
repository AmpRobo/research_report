### 9.1 概述

控制的目标是让实际机器人运动尽可能接近期望运动。

线性控制的核心假设是：在某个工作点附近，机器人或单关节可以近似为线性系统。虽然真实机械臂具有耦合、重力、摩擦和非线性，但线性控制仍是工业机器人控制的基础。
### 9.2 反馈与闭环控制

闭环控制持续比较期望值与测量值：

```
误差 = 期望值 − 实际值
```

控制器利用误差调整驱动输出。

反馈的价值：

- 减小模型误差；
- 抑制负载变化；
- 提高重复精度；
- 抵抗外部扰动；
- 自动修正部分传感器和执行器误差。

代价是：增益过大可能导致振荡、噪声放大、执行器饱和甚至不稳定。
### 9.3 二阶线性系统

单关节、质量块或等效机械系统常近似为二阶系统：

```
惯性项 + 阻尼项 + 弹性项 = 输入力/力矩
```

二阶系统最重要的两个指标是：

- **自然频率**：反映响应速度；
- **阻尼比**：反映振荡程度。

阻尼比过小会振荡，过大则响应慢；临界阻尼附近通常能在快速和不振荡之间取得平衡。
### 9.4 二阶系统的控制

对位置控制，最常见的是 PD 控制：

- P 项根据位置误差施加纠正力；
- D 项根据速度误差提供阻尼。

PD 控制可以把闭环误差动态设计成希望的二阶系统，因此可通过 \(K_p\) 和 \(K_v\) 设定响应速度与阻尼。

加入积分项后形成 PID 控制。I 项可消除恒定扰动导致的稳态误差，但可能带来积分饱和和额外振荡。
### 9.5 控制律的分解

控制律可分为两部分：

```
控制输出 = 基于模型的前馈项 + 基于误差的反馈项
```

- **前馈项**：根据期望位置、速度、加速度预先估算所需输入；
- **反馈项**：修正模型不准、摩擦、外力和传感器误差。

这种分解思想非常重要：模型负责“知道大致该用多少力”，反馈负责“看到误差后纠正”。
### 9.6 轨迹跟踪控制

位置调节只要求机器人停在某个固定点；轨迹跟踪则要求机器人在整个时间过程中跟随：

```
q_d(t)、q̇_d(t)、q̈_d(t)
```

轨迹跟踪控制器通常同时使用：

- 期望加速度前馈；
- 位置误差反馈；
- 速度误差反馈。

目标是使位置误差和速度误差都趋于零，而不是只在终点准确。
### 9.7 抗干扰

扰动可能来自：

- 负载变化；
- 外力接触；
- 摩擦变化；
- 电机力矩波动；
- 传感器噪声；
- 未建模柔性和齿隙。

稳定的闭环系统应具备 BIBO 稳定性：有界扰动不会造成无界误差。

对恒定扰动，纯 PD 控制通常仍可能存在稳态误差；提高 \(K_p\) 能降低误差，但不能无限提高。加入积分环节可以在理想情况下消除恒定扰动误差。
### 9.8 连续时间控制与离散时间控制

理论中常把时间看作连续变量；但数字控制器按采样周期工作。

```
连续时间：t

离散时间：t_k = kT_s
```

离散控制必须考虑：

- 采样周期；
- 零阶保持；
- 计算延迟；
- 量化误差；
- 差分求导引起的噪声放大；
- 积分饱和。

采样频率不足会降低相位裕度，使本来稳定的连续控制器在数字系统中产生振荡。
### 9.9 单关节的建模与控制

单关节通常由以下部分组成：

```
电机 → 减速器/传动 → 连杆与负载 → 编码器 → 控制器
```

其模型至少包含：

- 电机电阻、电感与反电动势；
- 电机力矩常数；
- 齿轮减速比；
- 等效转动惯量；
- 黏性摩擦；
- 重力或负载力矩。

实际工程常采用分层控制：

```
电流环：最快，控制电机力矩
速度环：中间层，控制关节速度
位置环：最外层，控制关节位置
```

位置环不能忽略电机电流、减速器、传动柔性和编码器位置，否则“控制的是电机角度”，不一定是实际关节角度。
