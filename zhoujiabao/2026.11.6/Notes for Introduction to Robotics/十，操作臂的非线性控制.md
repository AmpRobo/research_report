### 10.1 概述


第十章的重点方法是**计算力矩控制**：

```
利用动力学模型先补偿惯性、重力与耦合项
                +
利用反馈项消除跟踪误差
```

目标是把原本复杂的非线性机械臂，变换成便于设计的近似线性误差系统。

### 10.2 非线性系统和时变系统

线性时不变系统满足叠加性，系统参数不随时间或状态变化。

机械臂动力学则具有：

- **非线性**：重力、离心力、科氏力都包含非线性项；
- **时变性**：关节姿态改变时，等效惯量和耦合关系改变；
- **状态相关性**：同样的力矩，在不同姿态和速度下会产生不同加速度。

### 10.3 多输入多输出控制系统

多关节机械臂是典型的 MIMO 系统：

```
多个关节力矩输入
        ↓
多个关节位置、速度输出
```

一个关节施加力矩，往往会影响多个关节的运动。  
因此，逐关节独立控制只能近似处理；高性能控制应使用矩阵形式的增益与动力学补偿，显式处理耦合。


### 10.4 操作臂的控制问题

机械臂的标准动力学模型可写成：

```
惯性项 + 速度耦合项 + 重力项 = 关节力矩
```

控制问题是：已知期望轨迹

```
q_d(t)、q̇_d(t)、q̈_d(t)
```

如何计算力矩 \(\tau\)，使实际状态持续跟踪期望状态。

计算力矩控制通常由两部分构成：

- **模型补偿/前馈**：补偿 \(M(q)\)、\(C(q,\dot q)\)、\(g(q)\)；
- **PD 反馈**：基于位置和速度误差修正残余偏差。

理想模型准确时，误差可被设计成稳定的二阶线性系统。


### 10.5 实际应用中的问题

真实系统很难完全符合模型。常见误差来源：

- 连杆质量、质心和惯量标定误差；
- 负载变化；
- 摩擦、齿隙、柔性、传动弹性；
- 电机饱和与减速器效率；
- 编码器噪声和量化误差；
- 采样、计算和通信延迟；
- 外部接触力；
- 参数随温度、磨损和时间变化。

因此，模型补偿不能替代反馈控制。模型越不准，越需要稳健的反馈、合理的增益限制和安全的力矩饱和策略。


### 10.6 当前的工业机器人控制系统

工业控制器通常采用分层结构：

```
轨迹规划
    ↓
位置/速度外环
    ↓
关节伺服环
    ↓
电流/力矩内环
    ↓
电机与传动机构
```

典型工业系统常结合：

- 独立关节 PD/PID 伺服；
- 重力补偿；
- 速度与加速度前馈；
- 部分惯性和耦合补偿；
- 电流限制、速度限制、碰撞检测；
- 高速插补与实时通信。

完整非线性模型控制的性能更高，但对模型准确度、算力、传感器和工程调试要求也更高。

### 10.7 李雅普诺夫稳定性分析

非线性系统通常难以仅靠极点位置判断稳定性。李雅普诺夫方法不必显式求解系统轨迹，而是构造类似“总能量”的标量函数 \(V\)。

若满足：

```
V > 0：系统偏离平衡点时具有正能量
V̇ ≤ 0：系统能量不会增加
```

则可证明系统稳定；若 \(\dot V < 0\) 且满足相应条件，通常可以证明误差渐近收敛。

对机械臂控制，李雅普诺夫函数常由：

- 误差动能；
- 位置误差的势能；

构成。

### 10.8 基于笛卡尔空间的控制系统

关节空间控制直接跟踪 \(q_d\)。  
笛卡尔空间控制则直接关心 TCP 的：

- 位置；
- 姿态；
- 线速度；
- 角速度；
- 接触力。

适用于：

- 焊接、喷涂、打磨；
- 视觉引导；
- 插装与装配；
- 力控制和人机协作。

笛卡尔空间控制需要处理：

```
TCP 误差
    ↓
末端速度/力旋量
    ↓
雅可比矩阵
    ↓
关节速度或关节力矩
```

姿态误差不能简单用旋转矩阵逐元素相减，必须采用合理的三维姿态误差表达。


### 10.9 自适应控制

自适应控制用于处理模型参数未知或缓慢变化的问题，例如：

- 不知道准确负载；
- 搬运不同工件；
- 摩擦随温度变化；
- 连杆惯量和质心存在误差。

其基本思想是：

```
在线根据跟踪误差更新模型参数估计
        ↓
用更新后的参数计算控制输入
```

自适应控制能提高对参数不确定性的适应能力，但并不意味着可以忽略安全限制。参数估计的收敛通常还需要足够丰富的运动激励。
