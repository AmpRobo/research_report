### 8.1 概述
机械设计决定机器人的能力边界，包括：

- 可达工作空间；
- 有效载荷；
- 速度与加速度；
- 重复精度与绝对精度；
- 刚度与抗振性；
- 能耗、重量、体积与成本。

一个完整机器人系统通常包括：

```
操作臂 + 末端执行器 + 内部传感器
+ 外部传感器/工装 + 控制器
```
### 8.2 基于任务需求的设计

设计不应从“选一个六轴机械臂”开始，而应从任务开始。

应先明确：

- 工件质量、尺寸、重心和表面特性；
- 目标位置、姿态和路径；
- 工作空间范围；
- 节拍、最大速度、加速度；
- 精度、重复精度和力控需求；
- 环境条件，如洁净、防爆、高温、涉水或人机协作；
- 成本、维护和安全要求。

自由度并非越多越好。若工具绕自身轴旋转对任务没有影响，例如圆形砂轮、螺丝刀或旋转焊枪，则该姿态自由度可能不必严格控制。
### 8.3 运动学构形

机构构形指关节类型、排列顺序与连杆几何关系。

常见方案包括：

- 笛卡尔型：多为移动关节，工作空间规则、刚度较高；
- 圆柱型和球坐标型：适合特定包络范围；
- 关节型/多关节型：工作空间大、灵活，但运动学与控制更复杂；
- SCARA：平面高速装配优势明显；
- 带球形腕的六轴结构：位置和姿态较容易解耦，常便于闭式逆运动学。

构形选择本质上是在以下因素间取舍：

```
工作空间、灵活性、刚度、负载、速度、可维护性、控制难度、成本
```

### 8.4 工作空间属性的定量测量

工作空间关注：

- 是否覆盖所有任务点；
- 是否能提供所需姿态；
- 是否靠近奇异位形；
- 各方向是否都容易运动和施力；
- 是否存在关节限位造成的死角。

常用概念：

- **可达工作空间**：至少存在一组关节变量可以到达的位姿集合；
- **灵巧工作空间**：可实现所需全部姿态的区域；
- **可操作度**：衡量不同方向上运动与施力的均匀性；
- **条件良好工作空间**：远离奇异位形、雅可比矩阵数值性质较好的区域。

仅比较工作空间体积不够。一个体积很大的机械臂，可能大部分区域都接近奇异点或姿态受限。
### 8.5 冗余结构与闭链结构

**冗余操作臂**指机械臂自由度多于任务实际所需自由度。

优点：

- 可绕开障碍；
- 可远离奇异点；
- 可优化关节限位、能耗、刚度或姿态；
- 可在保持末端位姿不变时调整“肘部姿态”。

代价：

- 逆运动学解不唯一；
- 控制与规划更复杂；
- 机构重量、成本和故障点可能增加。

**闭链结构**则让末端通过多条机构支链与基座连接，如并联机器人。

优点：

- 刚度高；
- 负载能力较强；
- 运动部件可更轻，适合高速任务。

缺点：

- 工作空间通常较小；
- 存在约束与内部力；
- 运动学、奇异性和控制更复杂。
### 8.6 驱动方式

常见驱动方式：

- **电驱动**：易控制、清洁、精度高，是工业机器人主流；
- **液压驱动**：功率密度高，适合重载和大型机器人；
- **气动驱动**：结构简单、成本低、柔顺性好，但精确位置控制较难。

传动方式包括：

- 齿轮和减速器；
- 同步带；
- 丝杠；
- 链条；
- 钢丝绳/腱驱动；
- 直接驱动。

减速器能放大输出力矩并提高编码器等效分辨率，但也会带来摩擦、回程间隙、柔性和反射惯量等问题。
### 8.7 刚度与变形

机器人在载荷下必然产生变形，来源包括：

- 连杆弯曲与扭转；
- 关节轴承变形；
- 减速器扭转；
- 齿隙；
- 传动带、钢丝绳或柔性结构；
- 末端工具本身的柔性。

刚度不足会导致：

- 实际 TCP 偏离理论位置；
- 重载时精度显著下降；
- 高速运动产生振动；
- 力控不稳定；
- 重复精度与绝对精度恶化。

因此，设计时不仅要追求“大工作空间”，还要保证任务区域内足够的笛卡尔刚度。
### 8.8 位置检测

位置检测提供关节闭环控制所需反馈。常见器件：

- 增量式编码器；
- 绝对式编码器；
- 旋转变压器；
- 电位计；
- 直线光栅和磁编码器。

需要区分：

- **分辨率**：能区分的最小变化；
- **准确度**：测量值距离真实值的程度；
- **重复性**：多次回到同一指令时读数是否一致；
- **绝对位置能力**：断电后是否仍能知道真实关节位置。

传感器装在电机轴端不一定等于测到真实关节角，因为减速器齿隙与传动弹性会造成误差。
### 8.9 力检测

力检测是装配、插拔、打磨、研磨、触碰和人机协作的重要基础。

常见方法：

- 根据电机电流和动力学模型估计关节力矩；
- 在关节侧配置力矩传感器；
- 在腕部安装六维力/力矩传感器；
- 在夹爪或手指上安装触觉/压力传感器；
- 测量弹性元件变形，再依据刚度估算力。

六维力传感器通常输出：

```
Fx、Fy、Fz、Mx、My、Mz
```

力检测必须考虑传感器零偏、温漂、安装偏移、重力补偿和坐标系转换。
